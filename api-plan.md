# API Plan

## Сущности
- Product (игровая валюта / пополнение / и прочие цыфровые товары)
- User
- Order
- OrderItem

## Основные операции
- Просмотр каталога товаров
- Добавление товара в заказ
- Оформление заказа
- Просмотр статуса заказа



## Дополнительные операции
- Отмена заказа
- Просмотр истории покупок
